View layout · Free with Ultra Card Connect

Place any card anywhere.

FreeSpace is Ultra Card’s free-form dashboard view. Drag, resize, rotate and layer any Lovelace card on a canvas — with Desktop, Laptop, Tablet and Phone layouts, pins, and a real editor toolbar.

Get started GitHub docs

Turn it on in three steps

No switch to hunt for. Install Connect, pick FreeSpace as the view layout, and start arranging cards.

1

Install Ultra Card Connect

HACS → Integrations → Ultra Card Connect. Hub → Home then shows FreeSpace is ready.

2

Pick FreeSpace

Edit a dashboard → pencil the view → Layout → FreeSpace (Ultra Card).

3

Arrange freely

Add cards with the FAB. Drag to move, use handles to resize, rotate from the top-left icon, and layer with the toolbar.

Already using FreeSpace? Existing FreeSpace views keep rendering even without Connect. Connect unlocks the layout dropdown and edit tools.

Select & move

  • Click to select; empty space to deselect
  • Shift / Ctrl / Cmd-click or drag a box for multi-select
  • Cmd/Ctrl+A selects every card
  • Drag one selected card to move the whole group
  • Arrow keys nudge 1px (10px with Shift)

Edit & transform

  • Double-click opens HA’s card editor
  • Right-click or ⋮ for edit, duplicate, layer, pin, delete
  • Edge and corner handles resize
  • Top-left rotate icon (Shift snaps 15°)
  • On touch: press and hold a selected card to move it

Toolbar

Always shows Desktop / Laptop / Tablet / Phone, plus Use Desktop / Custom on the smaller sizes.

Nothing selected

Snap to grid (this session only) and Add card.

One card

X / Y / W / H / ° fields, Pin, Align to canvas, Layer, Edit, Duplicate, Delete.

Two or more

Align to the selection, Distribute (3+), Pin all, or Delete all (asks first).

Tight space

Button labels collapse to icons with tooltips when the toolbar gets narrow.

Pins

Control what happens when the screen is wider or narrower than when you placed the card. Set per card, per breakpoint, from the toolbar or right-click menu.

PinWhen the screen gets wider
Left (default)Keeps its distance from the left edge
RightKeeps its distance from the right edge
CenterStays the same distance from the middle
Left & rightKeeps both edge distances and stretches (never below 80px)

Pins only change the layout when Full width is on (Hub → Home → Layout width). With Full width off, the canvas width is fixed and every pin looks the same. While editing, a dashed line shows which edge the selected card is pinned to.

Breakpoints

Laptop, Tablet and Phone each start on Use Desktop. Move or resize a card there and that size switches to Custom, copying Desktop positions first so nothing else jumps.

BreakpointMin widthDefault artboard
Desktop≥ 1440px1200
Laptop≥ 1024px1100
Tablet≥ 768px768
Phone< 768px390

A card with no layout for a breakpoint always falls back to its Desktop layout. On phones, while Phone uses Desktop and narrow: stack is set (the default), cards stack in reading order until you arrange a Phone layout.

Config

Most people never touch YAML — FreeSpace settings live under FreeSpace view specific settings in the view editor. The shape looks like this:

type: custom:ultra-freespace-view
title: Living room
freespace:
  canvas_widths:
    desktop: 1200
    laptop: 1100
    tablet: 768
    phone: 390
  min_height: 800
  grid: 8
  narrow: stack # stack | scale
cards:
  - type: tile
    entity: light.sofa
    view_layout:
      desktop:
        x: 96
        y: 64
        w: 320
        h: 160
        r: 0
        z: 2

Sizing: Hub → Home → Layout width applies to FreeSpace and Sections. Full width fills the screen; otherwise the design canvas stays centred with dashed bounds in edit mode.

Import from Sections

Switch a Sections view to FreeSpace and an Import sections banner can flatten those cards onto the canvas in one save.
